# Zeno-paradoxes

Ce projet simule 3 paradoxes de Zénon:
1) Achille et la tortue: simulation discrète jusqu’au rattrapage.
2) Dichotomie: on parcourt toujours la moitié restante (convergence).
3) Flèche en vol: positions instantanées d’une flèche à vitesse constante.

Exécuter:
- python achilles_tortue.py
- python dichotomie.py
- python fleche_en_vol.py

Objectif: montrer que les simulations numériques lèvent l’illusion du “mouvement impossible”.Voici le résumé clair.
Contexte
Zénon d’Élée (présocratique, disciple de Parménide) utilisait des paradoxes pour contester la réalité du mouvement.
Trois paradoxes à illustrer:
Achille et la tortue: Achille rattrape une tortue partie avec de l’avance.
Dichotomie: on parcourt toujours la moitié de la distance restante (infinité d’étapes).
Flèche en vol: à chaque instant la flèche a une position fixe, ce qui semble nier le mouvement.
Ce qui est demandé (livrables)
Un dépôt GitHub public nommé zeno-paradoxes contenant:
Un script Python qui simule Achille et la tortue (mettre à jour les positions à chaque itération selon leurs vitesses).
Un script Python qui simule la dichotomie (réduire la distance restante de moitié à chaque étape).
Un script Python qui simule la flèche en vol (calculer/afficher la position à chaque instant).
Un fichier README expliquant:
le contexte et la problématique,
l’approche/solution pour chaque paradoxe,
les résultats des simulations (ce qu’elles montrent).
